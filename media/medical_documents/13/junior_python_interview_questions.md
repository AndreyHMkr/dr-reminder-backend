# Junior Python Developer – Interview Questions and Answers

## 🧠 Technical – Theoretical Questions

**1. Які основні типи даних є в Python?**  
List, Tuple, Set, Dictionary, String, Integer, Float, Boolean.  
`list` – змінний набір елементів, `tuple` – незмінний, `set` – унікальні елементи без порядку.

**2. Що таке змінна з точки зору Python?**  
Змінна — це ім’я, яке вказує на об'єкт у пам'яті. Python — мова з динамічною типізацією.

**3. Що таке `None` в Python?**  
Це спеціальне значення, яке означає «нічого». Часто використовується як початкове значення.

**4. Як працює передача аргументів у функції?**  
У Python аргументи передаються за посиланням на об'єкти. Змінювані типи можуть змінюватися.

**5. Що таке list comprehension?**  
Скорочений синтаксис для створення списку: `[x*2 for x in range(5)]`.

**6. Що таке декоратори?**  
Функції, які модифікують інші функції. Використовуються для логування, авторизації тощо.

**7. Які принципи ООП реалізовані в Python?**  
Інкапсуляція, Наслідування, Поліморфізм, Абстракція.

**8. Як працює обробка винятків?**  
За допомогою `try`, `except`, `else`, `finally`. Винятки перехоплюють помилки виконання.

**9. У чому різниця між `is` і `==`?**  
`is` перевіряє чи це один і той самий об'єкт, `==` — чи рівні значення.

**10. Що таке генератори?**  
Функції з `yield`, що повертають послідовність елементів без збереження їх у пам’яті.

## 🛠 Technical – Practical / Libraries

**11. Як отримати JSON з API?**  
```python
import requests
response = requests.get("https://api.example.com")
data = response.json()
```

**12. Як додати 5 днів до дати?**  
```python
from datetime import datetime, timedelta
new_date = datetime.now() + timedelta(days=5)
```

**13. Як протестувати функцію в pytest?**  
```python
def test_add():
    assert add(2, 3) == 5
```

**14. Різниця між @staticmethod і @classmethod?**  
`staticmethod` не має доступу до класу. `classmethod` приймає `cls` і має доступ до класу.

**15. Що таке virtual environment?**  
Ізольоване середовище для залежностей. Створення: `python -m venv env`

## 💬 Behavioral Questions

**16. Розкажи про помилку в коді. Як вирішив?**  
Очікується реальний приклад: аналіз, відладка, висновки.

**17. Як реагуєш, коли не розумієш завдання?**  
Уточнюю вимоги, ставлю запитання, працюю над прикладами.

**18. Пояснення технічної концепції нетехнічній людині?**  
Спрощення термінів, аналогії, візуалізація (наприклад, "функція — як інструкція з приготування чаю").

**19. Як організовуєш день?**  
Планування задач, пріоритети, перерви для відновлення фокусу.

**20. Як працюєш у команді з різними думками?**  
Слухаю аргументи, обґрунтовую свої рішення, йду на компроміси.
